# 盘点类型决定差异信息可见范围

盲盘过程中只展示差异数量，不展示具体差异商品；非盲盘可查看具体差异明细并导出，用于对照实盘结果、发现错盘和漏盘。盘点类型应依据公司的运营策略选择。
