# 盘点前准备与分区盘点组织方法

盘点前检查实物已入库或出库但对应单据尚未提交的情况，避免实物变化与系统账面不一致；整理货品、消除摆放死角，安排盘点人员和顺序并规划区域。货品较多时可按店仓结构分约10个区域，每区约100至200件商品，为各区域建立不同盘点号，分别录入并核对各区域数量。
