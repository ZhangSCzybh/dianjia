# 储值卡充值由联盟、预选项、赠送规则和员工状态共同约束

储值联盟影响会员及跨店场景的归属；后台关闭手动输入后，前台只能选择已配置的充值项；充值赠送规则决定赠品资格；服务导购只能从当前门店中系统性质为店长或导购且已激活的员工中选择。因此，充值异常应同时检查这些后台配置和员工主数据。
