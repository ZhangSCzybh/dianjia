# 异款换货按退货加购买并限制积分抵扣

异款换货需选择新商品并通过SKU、货号或条形码搜索。系统按退货加购买处理，结合商品金额、折扣和优惠券自动计算应退款或应收款。换单无法使用积分抵扣；若需积分抵扣，应先退货，再重新收单。
