# 实物充值赠品必须绑定本店可用SKU

实物赠品不能只记录抽象商品或赠品名称，前台需要选择具体SKU，库存扣减范围为本门店可用库存。赠送资格、SKU选择和库存可用性应作为充值交易验收与异常排查的检查点。
