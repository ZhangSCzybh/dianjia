# 盘点录入及错盘漏盘处理方法

商品明细支持扫描吊牌条码、手动输入货号、Excel导入和按规则文本导入。扫码未自动回车时，应切换英文输入法或检查扫描枪设置。错盘商品可在快速扫描中将加号切换为减号后再次扫描删除，也可盘点后按货号或SKU手动删除；漏盘商品可进入对应盘点号继续盘点，或新增盘点号补录。各区域录入后需核对盘点数与实物数量。
