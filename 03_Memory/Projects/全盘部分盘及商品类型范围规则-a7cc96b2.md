# 全盘部分盘及商品类型范围规则

全盘是对整个门店商品进行盘点，并依据盘点明细更新整个门店库存；部分盘只盘点手动选择或扫码选择的商品，并更新选定商品。商品类型可按普通、礼品、物料等需求筛选；盘点明细录入后若修改商品类型，不属于新类型范围的商品会被删除。
