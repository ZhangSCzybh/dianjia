# 零售补单的日期口径及财务对账差异

路径为“门店POS--收银台--零售补单”，可补录历史销售单和退单。补单时填写历史日期，业绩计入该历史日期，收款金额计入补单当天。数据银行统计补录及外部导入订单业绩，但财务零售单对账（门店支付统计）不包含这些订单，因此可能出现对账差异。
