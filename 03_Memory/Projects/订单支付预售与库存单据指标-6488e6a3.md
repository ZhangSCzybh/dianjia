# 订单支付预售与库存单据指标

字典覆盖零售-订单、预售-明细、支付-明细、出入库-单据/明细/发货/采购/配货/调拨/退货/调整、储值、礼品卡和积分兑换等分组。支付类区分支付金额、销售支付金额、销售实际交易金额、储值充值本金、礼品卡实销、付费会员购买和积分兑换；订单类含销售单、换货单、退货单及预售状态。出入库和销售数量按不同单据及时间字段统计，不能把支付状态、订单状态、预售状态或库存单据状态当作同一状态体系。
