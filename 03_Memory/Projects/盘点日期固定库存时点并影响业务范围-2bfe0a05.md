# 盘点日期固定库存时点并影响业务范围

系统通常默认盘点前一天；选择今天并保存后，盘点时点固定为当天23:59:59，不能选择实时盘点。营业期间创建盘点单时，营业结束后需刷新账面库存，才能纳入创建盘点单后发生的出入库。盘点历史日期时，今天出库的商品可能仍属于昨日库存范围，而今天刚入库的商品不应计入昨日库存，因此创建盘点单前必须确认目标库存时点。
