# 零售异款换货的金额折扣业绩与积分规则

选择异款换货后，可通过SKU、货号或条形码搜索新商品。系统根据商品金额、折扣和优惠券自动计算退款或收款；业绩按所选导购分配。换单过程不能使用积分抵扣，如需积分抵扣，应先退货再重新收单。
