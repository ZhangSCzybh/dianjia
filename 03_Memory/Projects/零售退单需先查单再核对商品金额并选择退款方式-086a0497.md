# 零售退单需先查单再核对商品金额并选择退款方式

操作路径为收银台 > 零售退单。订单可通过订单号、会员手机号、商品货号或SKU编码查询。确认订单后选择退款商品，核对商品与金额并提交，最后选择退款方式完成退单。退单改价仅在后台提前开放权限后可用。
