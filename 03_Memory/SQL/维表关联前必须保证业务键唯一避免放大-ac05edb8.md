# 维表关联前必须保证业务键唯一避免放大

销售和库存事实表关联商品、门店、首次到店、淘汰门店等维表前，应验证关联业务键的唯一性。对于门店加 SKU 等目标中间粒度，进入窗口函数或最终聚合前每个业务键最多保留一行。若维表存在重复有效记录，JOIN 会复制事实行，导致销量、库存、窗口汇总和动销指标被放大。应通过唯一性检查、显式去重或按业务规则选取唯一有效版本控制关联基数。
