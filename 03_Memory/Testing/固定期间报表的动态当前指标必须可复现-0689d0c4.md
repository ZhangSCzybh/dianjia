# 固定期间报表的动态当前指标必须可复现

当期间开始和结束日期固定，而当前库存、近 7 天销售、在店天数等字段依赖 today() 或 now() 时，同一 SQL 隔日运行会得到不同的当前指标，无法直接复现历史验收结果。应将当前基准日期或时间参数化并在执行记录中保存，或在统计时保留对应快照。近 7 天计算还应统一 Date 与 DateTime 语义，明确采用含今天的自然日窗口还是滚动 168 小时窗口，避免 addDays(today(), -7) 与 now() - INTERVAL 7 DAY 混用造成边界歧义。
