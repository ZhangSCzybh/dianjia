# 库存业务单据编号前缀与后缀识别规则

常用单据编号前缀包括：CK 出库单、RK 入库单、CJ 采购计划单、CG 采购订单、RKT 采购入库通知、CT 采购退货、CGTZ 采购调整、PD 盘点、TZ 库存调整、PH 配货、DB 调拨、CY 差异、THSQ 退货申请、TH 退货、DDSQ 订/补货申请、DH 订货、DHTZ 订货调整、ZX 装箱、CX 拆箱、PJ 商品/快速/订货配货、DJ 快速调拨、QCKC 期初库存导入。编号以 CX 结尾表示由冲销产生的单据；以 CY 结尾表示提交差异单后产生的库存调整单据。
