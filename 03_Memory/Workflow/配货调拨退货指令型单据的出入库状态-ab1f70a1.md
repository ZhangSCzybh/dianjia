# 配货调拨退货指令型单据的出入库状态

配货、调拨、退货等指令型单据的数据状态包括：已提交未出库、全部出库且未入库、差异出库且未入库、全部出库且全部入库、全部出库且差异入库，以及已完结。该状态体系用于识别指令单从提交到出库、入库和最终完结的执行进度及差异情况。
