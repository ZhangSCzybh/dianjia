# 店仓出入库差异单的生成与责任处理规则

收货方按实际收货数量提交入库单后，如存在少收或多发，系统自动生成差异单，用于追踪货物流向和判定责任。可从商家后台或收银台的“库存 > 差异单”进入，建议由商品人员在商家后台配置处理。处理方式包括：无需处理（不调整库存）；归属出库店仓（差异数量为-1时补回出库店仓库存，为1时扣减出库店仓库存）；归属入库店仓（差异数量为-1时补回入库店仓库存，为1时增加入库店仓库存）。完成每个商品的责任判定并提交后，系统调整责任方库存及其结算账户金额。可在关联出库单或入库单的备注中使用差异单号查询系统生成的差异调整单。
