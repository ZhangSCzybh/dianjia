# 2. 列表有时间维度

如果列表中已经包含时间字段：

```text
同环比粒度 = 列表时间字段的粒度
```

此时筛选控件只负责限制数据范围，不决定同环比粒度。

例如：

| 列表时间字段 | 同环比粒度 |
|---|---|
| 日期 | 日 |
| 年份 | 年 |
| 年季 | 季 |
| 年月 | 月 |
| 年周 | 周 |

所以，如果列表中有 `yearWeek`，即使筛选控件选择了“自定义日期”，仍然应按周进行同环比。
