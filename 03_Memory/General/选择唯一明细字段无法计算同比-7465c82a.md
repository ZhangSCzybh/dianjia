# 选择唯一明细字段无法计算同比

例如选择：

- 订单 ID
- 唯一流水号
- 明细 ID

这些字段在同期通常找不到相同值，因此无法建立同比关系。同比应基于可跨期间匹配的业务维度，例如：

```text
店仓 + 周次
品牌 + 店仓 + 周次
商品 + 周次
```

## 6. 对当前 SQL 的注意点

你之前的 SQL 中：

- `periodStart` 用 ISO 周的周一作为周起点，这个方向是正确的。
- 上期通过 `addDays(periodStart, -7)` 查找，表示前移一周。
- 环比公式也是正确的：

```sql
(本期金额 - 上期金额) / abs(上期金额)
```

但 SQL 中本期、上期、同期日期是硬编码的。以后更换查询日期时，必须同步修改：

- 本期日期
- 上期日期
- 同期日期
- `yearWeek` 筛选条件

不能只修改 `yearWeek`，否则周标签和实际金额日期可能不一致。

最核心的业务口径可以概括为：

> 周环比比较前一周，周同比比较上一年对应 ISO 周；部分周必须保持相同星期范围；跨年周按 ISO 周年判断；无匹配周或基准为 0 时不计算。
