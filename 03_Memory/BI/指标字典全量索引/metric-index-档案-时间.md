## 6. 周次

- 原始行号：681
- 字段分类：时间维度
- 指标名称：周次
- 技术编码：dateWeekName
- 用户解释：日期对应在本年中的第几周。
说明：周一为一周第1天，跨年（跨1月1日）的周归属哪一年，看这周的星期四在哪一年。如2026年1月1日所在周的周四为2026年1月1日，则该周（20251229~20260104）为2026年的第一周。
假设周四在2025年，则26年第一周为260105~20260111
- 内部说明：ISOWEEKNUM(日期)：周一为一周第1天，1月1日所在周为上一年年末，则周次为上一年的周次，1月1日的下一个周为当年的第一周。如2022年第1周的第一天为1月3日
WEEKNUM(日期)：周日为1周第1天，每年1月1日为第1周的第1天，1月1日之后的第一个星期日为第2周的第1天。如2022年1月1日（周六）为第1周，2022年1月2日（周日）为第2周的第1天
当前数据银行采用的是ISOWEEKNUM
