## 3. 订单最近配入单价

- 原始行号：807
- 维度/指标：维度
- 字段分类：订单商品
- 指标名称：订单最近配入单价
- 技术编码：saleGoodsLastAllocInPrice
- 用户解释：零售订单当时关联的最新一次配货入库单价。
如商品X店铺A在1号配货入库单价60，1号销售的订单的最近配货入库单价记60；5号再次配货入库，单价40，则5号销售的订单最近配货入库单价记50
- 内部说明：零售组提供。A店商品由B店代发的，取A店的最近入库单价
13581新疆百腾定制，其他商户默认不开放

补录的订单单价为0（不按补录时最新配入单价算，不按补录的业务时间取）；
1天多个配入单（相同单据日期的）优先取提交时间最晚的单据。退单关联原单取原单成本。
换货单的负项和退货单的商品关联原单取原单的销售。

订单加权平均价业务可以重新跑，但是最近配入单价不可修复调整
