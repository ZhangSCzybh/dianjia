- 指标名称：实时采购在途
- 技术编码：transitPurchaseNum
- 指标别名：采购未入库数
- 用户解释：已提交、未完结的采购订单剩余未入库数量，采购数量-已入库数量，

说明：和业务实时库存查询的【采购在途】定义不同，业务的【采购在途】为未提交的入库通知单数量
- 内部说明：采购订单完结，则所有商品算完结（业务未往下存）；
页面上有订单完结和商品完结的按钮，不限商户，具体是订单完结还是商品完结看用户具体操作。
