单据下游分批出入库的，维度中的关联业务单数量不拆分，指标中对应业务单数量按出入库先后顺序拆分。

1笔出入库单关联的上游单据，若关联多个下游单号（出库单看上游单号关联的出库单，入库单号看上游单号关联的入库单），按出入库单的时间先后顺序分配关联业务单数量，分配完即止，未分配完的计入最后一笔入库单。

②采购入库数量合计＜采购数量，如1笔采购订单采购40件，对应采购2笔采购入库单，分别对应入库数量10,20。则各采购入库单对应关联业务单数分别为10,30
③存在出库单差异单的，负数按负数的记。如配货单40件，对应3笔退货出库单，数量分别为10，-10（未入库，生成出库单CKXXXXXXCY-10）,30，则各配货出库单关联的业务单数分别为10，-10，40
- 内部说明：入库单，显示正数；
出库单，显示负数。
无关联业务单的，显示0

说明：单据下游分批出入库的，对应业务单数量不能直接汇总，汇总会重复
