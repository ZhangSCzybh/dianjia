## 13. 累计订货配货欠数

- 原始行号：2128
- 分组备注：原始分组单元格为空，按前一非空分组归档
- 维度/指标：指标
- 字段分类：累计订配发
- 指标名称：累计订货配货欠数
- 页面名称：根据规则计算
- 技术编码：applyoutAccumulativeApplyAllocateOwnNum
- 指标别名：累计订货欠数（配货）
- 用户解释：截至所选期间末已提交的订货单，截至最新统计时间累计待配货的件数。
订货单已完结，订货配货欠数=0
订货单未完结，订货已配数≥订货数，订货配货欠数=0；
订货单未完结，订货已配数＜订货数，订货配货欠数=订货数-订货已配数；
（注意：按单笔订货单判断，再汇总。不是直接用累计数量计算）
- 内部说明：业务订货欠数逻辑：
配货未出库，订货欠数=未配货数量=订货数量-配货数量；
配货已出库，商户允许多次出库的（看商户配置是否可多次出库），未考虑。
配货已出库，商户不允许多次出库的（1笔配货单对应1笔出库单），订货欠数=订货单的（订货数量 - 配货数量） + 出库单的（配货数量 - 出库数量）
