## 1. 会员复购金额

- 原始行号：2671
- 字段分类：是否会员
- 指标名称：会员复购金额
- 技术编码：saleRepurchaseCustomMoney
- 用户解释：所选期间内产生2次及以上有效购买行为的会员的销售金额。
参照【销售金额】的定义配置剔除商品或支付方式，默认剔除支付方式。
复购的定义与所选组织范围无关，复购相关的指标数据与所属组织范围有关。如新会员X在A门店消费1次，在B门店消费1次，则A、B门店新会员复购人数均+1；
