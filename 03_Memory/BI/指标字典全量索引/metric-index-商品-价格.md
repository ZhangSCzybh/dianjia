- 指标名称：店仓配调入库均价
- 技术编码：priceStorageAllocTransferInAvg
- 用户解释：店仓+SKU所有配货/调拨入库单的加权平均单价，与所选时间控件无关。

第2次入库30件，单价100元/件。
