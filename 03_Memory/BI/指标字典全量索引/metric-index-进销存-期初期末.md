## 10. 期末采购在途

- 原始行号：1810
- 维度/指标：指标
- 字段分类：期初期末数量
- 指标名称：期末采购在途
- 技术编码：stockmanagePeriodEndPurchaseTransitInventoryNum
- 用户解释：截至所选期间末，已采购，未到货的商品数量。
①采购单商品已完结，完结当日的期末采购在途数量记0；
②采购单商品未完结，统计采购单已提交、采购入库单未提交的数量。即采购在途 = 采购单数量-采购入库数量，按入库店仓统计，时间按单据日期计算； 
③采购单商品未完结，若商品超入，即采购单数量-采购入库数量小于0，采购在途=0。是否超入的判断到商品粒度，不到单据粒度
采购入库单无上游采购单，则无采购在途数量。
④冲销、撤回：
A.采购入库单已生成的，上游采购单不可冲销/撤回。 
B. 采购入库单、采购单冲销/撤回，更新历史在途数据；
- 内部说明：采购单完结，则采购单中所有商品均算完结。

采购单完结，不影响历史的期末采购在途，只影响完结后的期末采购在途。如1号采购订单10件，2号入库2件，3号完结，则2号期末在途8件，3号期末在途0件。
