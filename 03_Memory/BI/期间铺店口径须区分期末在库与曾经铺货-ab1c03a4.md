# 期间铺店口径须区分期末在库与曾经铺货

期间铺店 SKC/SPU 可定义为期间期末库存近似值大于 0，或期间普通销售净量大于 0；期间动销则以期间普通销售净量大于 0 判定。在该定义下，期间入库后全部调出、期末库存为 0 且无普通销售的对象不会被计入期间铺店。因此“期间铺店”必须明确是表示期末仍在店或期间有售出，还是表示期间任意时刻曾有库存；后者需要基于库存时点或完整出入库事件另行实现，不能由期末库存近似值替代。
