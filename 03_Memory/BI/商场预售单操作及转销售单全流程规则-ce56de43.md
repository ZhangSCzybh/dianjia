# 商场预售单操作及转销售单全流程规则

商场预售单用于商场店冲业绩场景，操作与销售单录单步骤一致，需将销售单切换为商场预售单。预售单可转为销售单，转正后订单状态变为已完成，下单时间和完成时间取当前转入时间，订单来源显示为'商场预售转入'。库存方面：生成预售单时占用商品库存，转销售单后释放占用库存并扣减期末库存。支付方面：生成预售单时生成支付记录并关联预售单号，转销售单后支付不做处理。会员方面：生成预售单时积分抵扣值预扣并关联预售单号，转销售单后正式扣减；会员积分和升降级在转销售单后才触发计算；储值卡支付时生成预收单并记录使用流水，关联预售单号。预售单转正时会校验门店日结状态，已日结则不能转正；POS端有校验，SHOP后台未加校验，日结后运营人员不要在shop端操作预售转销售单。操作路径：门店POS-订单-商城预售/本店订单；库存查询路径：门店POS-库存-库存查询；预售报表可在数据银行查看。

## 更新 2026-08-31

已付全款的商品预售单可点击'转成销售单'按钮转成销售单，二次确认后预售单状态变为'已完成'，系统自动生成待提交状态的出库单（占用库存），同时进行会员权益、数据等运算。支持在预售单管理页面勾选多个预售单批量转成销售单。shop端和POS端的商品预售管理页面均可导出预售单报表和商品报表。转入的销售单可在订单管理中选择订单来源'商品预售转入'查询，销售订单详情页在订单号下方透出关联预售单号。转成销售单后：邮寄订单状态为'待发货'，点击'发货'时校验库存，库存不足无法发货，发货后可修改物流；自提订单状态为'待发货（待提货）'，点击'确认自提'二次确认后核销并扣减库存，订单状态变为'已完成'，核销时校验库存，期末库存不足无法自提。订单列表中分别展示定金和尾款的支付方式明细。智慧财务-零售-门店支付统计中，查询项'零售类型'增加了'预售'选项。
