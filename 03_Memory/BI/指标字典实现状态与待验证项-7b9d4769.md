# 指标字典实现状态与待验证项

字典上传标识统计约2484条上传、36条待新增、10条删除、15条它表已有及147条不用；基础/计算分类约1894条基础、201条计算，并存在新增、保留、优化等状态。部分行缺少指标编码、报表或维度/指标分类，内部说明中明确业务无存储、需关联 SCM、组件上自定义或暂不添加。敏感权限分组包含成本、总部成本、供应商、商品、员工等，商户可见和小二默认权限不能由空值推断为公开。对待新增、删除、暂不放、未确认 CASE 或截图/外部链接内容，应保留待验证状态，不能当作已上线事实。
