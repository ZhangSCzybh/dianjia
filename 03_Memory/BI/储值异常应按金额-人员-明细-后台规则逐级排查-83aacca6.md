# 储值异常应按金额、人员、明细、后台规则逐级排查

第一步在门店汇总确认差异属于充值、赠送、调整、消费还是退款；第二步在员工汇总核对人员归因；第三步下钻账单明细核实会员、充值项、赠品和备注；第四步回查储值联盟、充值预选项、赠送规则及员工激活状态。该路径可形成从异常金额到具体交易和配置的可追溯链路。
