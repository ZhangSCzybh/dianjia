# 报表中心属性更新频率：维度实时更新，属性15分钟延迟

报表中心属性信息更新频率说明：维度（商品、店仓渠道）资料信息维护修改后，数据实时更新，但属性资料更新频率为15分钟。例如商品A的季节维护为夏季，数据实时更新；但季节属性中“夏季”字段修改名称为“夏季1”，数据15分钟更新。因此，属性修改后数据未更新可能是由于尚未达到15分钟刷新周期。
