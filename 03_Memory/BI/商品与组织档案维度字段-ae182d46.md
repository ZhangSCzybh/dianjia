# 商品与组织档案维度字段

档案-商品约195条维度，覆盖SPU/SKC/SKU图片、名称、货号、颜色、尺码、条码、商品类型、类目、品牌、年份、季节、价格带、供应商、销售属性等。档案-会员约196条维度，覆盖会员信息、标签、入会、来源、消费偏好等。档案-店仓渠道约141条，档案-人员约114条，另有供应商、部门、时间等档案维度。部分字段明确标记暂不添加、待新增、业务无存储或需额外关联 SCM，不能把空编码当成可用字段。
