# 储值卡账单按门店、员工和明细三层核对

门店汇总应观察充值、充值退款、充值调整、赠送、赠送回退、消费和退款等完整资金链路；员工汇总重点分析导购带来的充值与赠送；账单明细用于定位具体会员、交易和赠品记录。导出时应区分仅下载已选字段与下载全部字段，审计或异常分析应优先保留全量字段。
