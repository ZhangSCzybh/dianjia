# 商品预售单录入、支付与订货单生成规则

商品预售单用于新品或爆款断货等场景的预售，正式使用前需完成前期配置。录入方式：点击'销售单'下拉选项中的'商品预售'，需设置配送方式为'快递配送'或'自提'，未设置则无法提交订单。会员积分、优惠券、优惠码等优惠与销售单相同。支付方式：点击'提交订单并支付'可选择'支付全款'或'支付定金，后付尾款'；定金金额必须大于0且小于订单总金额。会员一次性支付全款或补齐尾款后，订货单菜单生成对应订货单，可勾选多条单据生成采购计划单、采购订单或配货单。付款状态包括：待付款（未付款）、部分已付款（定金已付尾款未付）、已付全款（全款或定金+尾款均支付完成）。待付款订单可超时或手动关闭订单；定金已付的订单可点击'支付尾款'完成剩余支付。
