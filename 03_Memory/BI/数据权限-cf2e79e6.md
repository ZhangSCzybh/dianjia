# 数据权限

数据权限
说明：老报表中用户系统性质为总部人员、供应商的，渠道权限勾选后不生效，报表中心勾选后会生效，上线前请注意权限选择。
店仓通用组件可见店仓逻辑：有配置数据权限的按数据权限，未配置数据权限的按所属店仓（不管所属渠道）；无数据权限且无所属店仓的，无可见权限。   -- 新老报表
基础数据权限可见店仓逻辑：有配置数据权限的按数据权限，未配置数据权限的按所属店仓+所属渠道权限；无数据权限且无所属店仓/渠道权限的，无可见权限。  -- 仅针对新报表
1、组织权限（店仓/渠道权限）
①用户系统性质为总部人员、渠道管理员、供应商：走基础数据权限；
②用户系统性质为店长、导购：
      报表中心【库存明细】：有配置数据权限的，走基础数据权限；未配置数据权限的，默认归属店仓+归属店仓所属渠道的权限。
      其余数据：统一按归属店仓+归属店仓所属渠道控制权限。与数据权限模板设置无关。
      若店长导购的其他数据也需要查看其他权限，请调整系统性质。
基础数据权限逻辑：配置的 渠道 + 店仓+店仓所属渠道
说明：渠道、店仓所属渠道的权限，都是针对单据直接到渠道粒度的数据。如渠道A下有店仓A1、A2、A3，则：①若用户只配置了渠道权限，则用户只可见单据直接到渠道A的数据，不包含单据到店仓A1/A2/A3的数据；
②若用户配置的权限为店铺A1, 则用户可见店铺A1的数据和店铺A1所属渠道A的数据（单据直接到渠道A的计入，单据到店铺A2/A3的不会计入）
