# 会员报表礼品卡余额统计范围

会员销售分析和会员明细仅统计会员数据，礼品卡流水、礼品卡汇总分析还包含匿名会员信息，优惠券同理。礼品卡汇总余额考虑礼品卡可能无会员归属，因此不按会员归属门店统计，而按销卡门店统计；会员销售分析则按会员归属门店统计。
