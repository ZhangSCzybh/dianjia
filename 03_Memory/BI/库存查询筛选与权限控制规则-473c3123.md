# 库存查询筛选与权限控制规则

商品货号、店仓和供应商支持模糊搜索；货号输入框右侧的查询条件入口可进行条件查询；开启“排除零库存”可过滤库存为零的门店；若界面缺少导出按钮或商品展示字段，应由商户管理员检查权限配置。
