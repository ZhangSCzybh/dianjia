# 数据同步问题：删除、合并、重建后数仓数据未更新

数据同步问题记录：1. 会员合并：老会员和微信会员融合，老数据未及时更新删除；2. 业务删除：店仓、商品删除后数据未删除；3. 聚水潭换绑SPU：聚水潭过来的商品，用户删除商品又重建的，在数仓这边是不删除的。这些问题表明数仓在删除、合并、重建等操作后可能存在数据残留或未同步的情况，需关注相关同步机制。
