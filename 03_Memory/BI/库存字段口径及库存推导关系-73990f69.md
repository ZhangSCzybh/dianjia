# 库存字段口径及库存推导关系

期末库存=可用库存+占用库存，不含在途库存；可用库存=期末库存-占用库存；占用库存包括已提交出库单或零售单但尚未出库的数量，按出库店仓统计；在途库存包括已出库但入库单未提交，以及采购订单生成的采购入库单未提交数量，按入库店仓统计，入库单被作废的数量不计入在途；采购在途库存是采购订单生成的采购入库单未提交数量；预计库存=期末库存+在途库存。
