# 零售与预售报表支付方式拆分口径

零售明细销售金额由配置剔除支付方式或商品，本身不到支付方式粒度，按支付方式展示时按比例拆分而非实际拆分。预售已付定金和尾款同样不到支付方式粒度，订单只知道关联支付方式而不知道定金/尾款各自支付方式，因此按订单支付总额比例拆分；例如定金用礼品卡、尾款用储值卡时不能按支付方式还原真实阶段归属。支付方式为无时，竖排中有商品无金额但有数量会显示该记录；整单金额为0的场景仍待解决，部分商品金额为0已解决。
