# 零售销售金额与单效指标

零售-明细指标包括标准吊牌额=销售数量*标准吊牌价、订单吊牌额=订单详情吊牌价*销售数量、标准零售额=销售数量*标准零售价、商品销售价总额、优惠金额合计、商品实付金额、运费、销售数量、销售金额、单效销额和单效数量。销售金额根据配置决定剔除商品/支付方式及是否含运费；单效销额用于客单价、折扣率等指标，单效数量用于件单价。客单价=单效销额/单效单数，连带率=单效数量/单效单数；单效单数可按配置选择销售单数或订单笔数。运费按商品实付金额比例分摊，整单商品金额为0时需避免按0%分摊。
