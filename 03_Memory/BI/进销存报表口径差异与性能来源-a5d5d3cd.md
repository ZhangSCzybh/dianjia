# 进销存报表口径差异与性能来源

进销存分析勾选不为0在报表中心按所选字段数据结果过滤，多维报表基于数据集所有字段而非右侧展示字段。查询慢的原因包括历史日期仍关联实时库存到期末信息（约2~3秒），以及实时采购在途需计算全部采购订单和采购入库单（约6~7秒）。出入库明细以出入库信息为准，盘盈盘亏数量为0的盘点记录不呈现；盘点明细报表以盘点单为准，即使数量为0也呈现。零售出入库数量按出入库时间和单据统计，销售数量按订单支付时间统计，来源和时间差异以及已销售未发货都会造成不一致。
