# 报表中心敏感字段权限与虚拟数据规则

报表字段排查：超管有字段而其他角色没有时检查敏感字段权限和字段权限；超管也没有时先确认10010账号是否存在该字段，再请客服检查小二权限，均不存在时提需求。成本、手机号、供应商、采购价、各种成本价以及考虑加盟场景的商品年份属于敏感字段，需设置敏感字段是否可见。为保证设计报表效率，设计页数据是虚拟数据，仅供样式参考。
