# 会员销售与新老会员指标

会员-个人指标包含累计销售金额、数量、销售单数、订单笔数、单效单数、成交/销售次数、成交/退货数量和金额等；会员-拉新包含新增会员销售金额、单效金额、单效单数、客单价、件单价、连带率、折扣率和成交人数；会员-零售包含新会员第1次消费、期间消费和首销回购等。会员成交人数需按会员去重，同一天同一家门店多次购买按业务规则处理；跨店会员仍按品牌会员归类，统计门店口径必须依据指标定义区分开卡门店、会员归属门店和销售门店。
