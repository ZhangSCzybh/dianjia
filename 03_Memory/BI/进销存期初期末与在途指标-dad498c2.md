# 进销存期初期末与在途指标

进销存-期初期末定义期初库存、采购/调拨/配货/退货在途、流转在途、总在途和预计库存；例如期间为1月3日至1月28日时，期初取1月2日期末。期末库存数量=期初库存数量+进销存净入库数。期末采购在途=已提交采购单数量-采购入库数量，已完结商品完结当日记0；调拨在途=截至期末已提交调拨出库数-未提交调拨入库数，负数按0；配货在途、退货在途遵循对应单据状态。
