# 商品预售单转销售单后退款规则

全款支付的商品预售单转成销售单后，退款流程与正常销售单一致，查找订单走退款流程即可。定金方式的商品预售单转成销售单后，退款优先从可退尾款金额中退款：当需退金额≤可退尾款金额时，从尾款中退款；当需退金额＞可退尾款金额时，先从尾款退款，不足部分从定金退款（生成两笔退款申请）；若存在多笔退款且可退尾款金额已为0，直接从定金中退款。特殊环境下若尾款退款成功但定金退款未成功，可发起重新退款。注意：商品预售单转成的销售单暂不支持换货功能；商品预售单不可退定金，需转成销售单后再发起订单退款。
