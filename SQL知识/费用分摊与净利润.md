# 费用分摊与净利润指标

## 一、费用分摊

费用明细来源表：`flowload.dm_finance_cost_detail`

费用项目来源表：`flowload.dm_finance_cost_project`

待分摊费用金额：

```text
mix_money = (cost_ready_draw_money + cost_apportion_money) / 10000
```

费用分摊比例：

```text
cost_type_zb = round(sumMix_money / storage_day_cost_money, 4)
```

其中：

```text
sumMixMoney = 待摊费用 + 费用分摊金额
storage_day_cost_money = 同一门店、同一天的全部费用金额
```

例如同一门店 08 月 01 日有：

```text
投诉费 344
快递费 100
补偿费 216.15
总费用 660.15
```

则投诉费初始分摊比例为 `344 / 660.15`，快递费比例为 `100 / 660.15`，补偿费比例为 `216.15 / 660.15`。

## 二、净利润

标准净利润：

```text
标准净利润 = sale_money_total_num_new
           - sale_total_stand_cost_money_new
           - sumMix_money
```

标准净利率：

```text
标准净利率 = 标准净利润 / sum(sale_money_total_num_new)
```

总部综合净利润：

```text
总部综合净利润 = sale_money_total_num_new
               - sale_total_zh_cost_money_new
               - sumMix_money
```

总部综合净利率：

```text
总部综合净利率 = sum(sale_total_zh_net_profit)
               / sum(sale_money_total_num_new)
```

## 测试关注点

- 同门店同一天的费用是否完整进入分母。
- `cost_ready_draw_money` 和 `cost_apportion_money` 的单位换算是否除以 10000。
- 当日总费用为 0 时是否有除零处理。
- 费用金额、成本金额和销售金额的汇总粒度是否一致。
- 净利率分母为 0 时页面/API 的展示规则。
- 费用项目编码与 `flowload.dm_finance_cost_project` 是否能完整关联。
