# POS 收单流程与规则

收单可分为五步：1.录入商品；2.录入会员；3.处理优惠组合；4.提交订单收银；5.打印小票，门店人员可根据此步骤来进行收单。

## 录入商品

门店人员可根据以下四种方式来录入商品：

1. 鼠标光标放在输入商品处，用扫码枪扫描商品吊牌上的条码，扫描后商品会自动展示在收单的列表中。
2. 点击筛选器按钮，通过页面上的筛选条件进行查找要收单的商品。
3. 手动输入要收单的商品 SKU 编码，回车后添加对应商品。
4. 输入某款商品的货号，回车或者点击查询，在弹出页面里面添加要收单商品的颜色尺寸；选择颜色尺码时，右上角会展示该商品的本店库存或者可用库存。

- 本店库存：所在门店里这个 SKU 的库存。
- 可用库存：所在门店的门店联盟总库存，门店联盟的库存可以共享。本店库存为 0、可用库存不为 0 时，表示其他门店有该商品库存，仍可进行收单。
- 强制负库存收单：选择后商品库存会变为负数，需管理员开启权限。
- 向其他门店发起缺货调拨：由其他有货门店帮助本门店调拨发货；缺货商品会显示调拨图标，门店人员需按客户需求设置配送方式。
  - 快递配送：由调拨门店直接快递发货给客户。

### 新增会员地址

默认取会员管理 → 会员详情 → 会员档案中的收货地址。会员档案地址为空时，需要新增会员地址；新增后可勾选添加到会员收货地址。

### 稍后填写邮寄地址

门店 POS 收单时，本店无货需其他门店调拨，或客户在景区旅游购物选择邮寄时，可在提交订单后通过零售小票上的二维码填写邮寄地址。需后台开启权限。

操作权限路径：shop 后台 → 设置 → POS 设置 → 到店设置 → 设置策略 → 打开“允许提交订单后，填写邮寄地址（只适用调拨订单）”。

#### 小票扫码填写地址

1. 在小票设置中勾选“邮寄地址二维码”并保存；小票最下方会显示用于填写该订单地址信息的二维码。
   操作路径：shop 后台 → 订单 → 小票设置 → 勾选“邮寄地址二维码”。
2. 使用自定义小票时，进入设置 → 打印模板，选择“零售小票”后点击“新增”或“设计”；在“基础字段”选择“邮寄地址二维码”并拖入右侧预览，完成后保存。

### 到店自提

调拨门店给本门店发货，会员在本门店提货时，需填写会员姓名和手机号，以便到货后通知会员到店取货。

### 录入商品注意事项

1. 后台若只设置扫描录入商品，则只能通过扫码枪录入，其他方式不支持。
2. 邮寄地址只能填写一次，后期不可更改。

## 录入会员信息

门店人员收单时可通过手机号、微信会员卡卡号、会员识别码三种方式录入会员。后台可限制门店允许的识别方式；若仅配置一种方式，其他两种方式不可用。

客户不是会员时，收单无需录入会员。

操作权限路径：shop 后台 → 设置 → POS 设置 → 到店设置 → 设置策略 → 允许的会员录入方式。

1. 光标放在输入框内，用扫码枪扫描会员微信卡包中的会员码。
2. 用扫码枪扫描会员微信公众号会员中心的识别码。为防盗刷，识别码的有效期由后台会员码时效设置决定；若设置为 1 分钟，则该会员码扫码一次后在 1 分钟内失效，1 分钟后可再次扫码。
   权限操作路径：shop 后台 → 会员 → 基础设置 → 会员码时效设置。
3. 手动输入会员手机号、微信会员卡卡号或会员中心识别码（会员码）。

## 商品折扣与优惠组合

录入商品和会员后，门店人员处理订单优惠信息：

- 可手动设置单个商品是否享受会员折扣，修改商品单价、折扣或金额；需管理员开启权限。
  权限路径：shop 后台 → 设置 → POS 设置 → 到店设置 → 设置策略 → 允许对单个商品设置是否享受会员折扣／允许修改商品折扣或销售价格。
- 可查看订单商品活动和会员名下可用优惠券；系统自动选择最优组合，无需手动选择配置。
- 会员卡等级有折扣时系统默认使用，但门店人员可选择整单不使用会员折扣。
- 有积分时，系统展示最大可抵扣积分；可直接选择、手动输入积分抵扣金额或不使用积分。为防止冒用，后台可设置使用积分抵扣时必须通过手机短信验证码验证。
  权限路径：shop 后台 → 设置 → POS 设置 → 到店设置 → 设置策略 → 允手机号录入 → 手机短信验证。
- 管理员开启商家优惠权限后，门店人员可以填写订单的品牌优惠；额度限制由后台设置。这是所有优惠计算完成后门店提供的额外优惠。
  权限路径：shop 后台 → 设置 → POS 设置 → 到店设置 → 设置策略 → 允许使用“品牌优惠”。

## 选择付款方式和收银

- 右下角可选择订单录单导购。一笔订单可有多个导购：后台配置为多导购平均分时，选择多个导购即可由系统均摊业绩；配置为固定比例分摊时，选择多个导购后调整业绩比例，由系统按比例分配。
  权限路径：shop 后台 → 设置 → 通用设置 → 收单时的业绩设置。
- 商场店类型店铺需填写商场收银金额，供财务后续对账；非商场店无需填写，直接提交订单支付。
- 点击提交订单后，根据客户需求输入付款金额并选择支付方式。为防止会员储值卡盗用，后台可设置使用储值卡需手机短信验证；开启后需发送并填写正确验证码，方可使用储值卡余额支付。
  权限路径：shop 后台 → 设置 → POS 设置 → 到店设置 → 设置策略 → 允手机号录入 → 手机短信验证（与积分抵扣的验证设置相同）。

## 打印小票与字段口径

支付成功后可打印小票。字段解释：

- 吊牌：商品吊牌价格。
- 折扣：商品本身折扣，零售价／吊牌价。
- 销售：商品零售价／单价。
- 数量：商品数量。
- 金额：商品零售价总计，商品零售价 × 数量。
- 优惠：商品总共优惠金额，包含商品自身折扣扣减金额，以及商品折扣后叠加会员折扣和其他活动扣减金额。
- 实折：商品自身折扣后叠加会员卡折扣，最终付款金额相对吊牌价计算的实际折扣。
- 实付：商品所有折扣后的实际付款金额。
- 总价：订单中所有商品的吊牌价总价。
- 会员优惠：仅会员卡实际优惠的金额。

### 小票计算示例

钻石顶级卡会员购买两件女装：每件吊牌价 688 元、零售价 588 元；门店满 600 元减 50 元，且可与会员折扣叠加；会员等级折扣为 5.5 折。最终实付 619.30 元。

- 吊牌：688 元；销售：588 元；商品本身折扣 = 588 ÷ 688 = 8.55 折。
- 两件零售价合计 1,176 元，满减 50 元后合计 1,126 元，单件折后零售价为 563 元。
- 单件实付 = 563 × 0.55 = 309.65 元；两件实付合计 619.30 元。
- 单件优惠 = 688 - 309.65 = 378.35 元。
- 实折 = 309.65 ÷ 688 = 0.450，即 4.50 折。
- 会员优惠 = 1,126 × (1 - 0.55) = 506.70 元。
- 总价 = 688 × 2 = 1,376 元。
