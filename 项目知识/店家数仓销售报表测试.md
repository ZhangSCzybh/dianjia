# 店家数仓销售报表测试

## 数据链路

```text
HR / SCM / ERP / 零售 / 批发
    -> FlowET 清洗转换
    -> DTS / FlowDTS 同步
    -> 阿里云 ClickHouse
    -> FlowAPI / FlowBI
    -> 报表中心、BI、标签及业务数据服务
```

## 测试分层

1. 源数据层：字段、类型、主键、数据量、更新时间。
2. 同步层：漏数、重复、延迟、断点续传、重复消费。
3. ETL 层：字段映射、过滤、去重、幂等、退款转换。
4. 数据集层：源表与数仓表记录数、金额和最大业务日期对账。
5. 组件层：聚合、去重计数、Join 基数、空值和维度分组。
6. 面板层：筛选器、合计、同比环比、导出、接口与页面一致性。
7. 权限层：品牌、门店、角色和多集群数据隔离。

## 周销售报表基准

对 2026 年第 35 周：

```text
本周：2026-08-24 至 2026-08-30
上周：2026-08-17 至 2026-08-23
去年同期：2025-08-25 至 2025-08-31
```

当前周尚未结束时，应另做周累计：当前周与上周、去年同期使用相同已过去天数比较。

## 必测 SQL 风险

- 一对多 Join 后直接汇总主表金额。
- `count(*)`、`count(id)`、`count(distinct id)` 口径混用。
- 使用手机号为空判断非会员。
- 会员维表按当前销售店铺过滤，遗漏跨店归属会员。
- `between` 处理日期时间边界导致漏数。
- ReplacingMergeTree 未验证 `FINAL` 前后结果。
- 退款金额、取消单、零金额单未按指标口径处理。
