# 订单与预售状态码

## 支付状态 pay_status

| 值 | 含义 |
|---:|---|
| 1 | 待支付 |
| 2 | 已支付 |
| 3 | 支付中 |
| 4 | 取消 |
| 5 | 支付定金 |

## 预售 bill_status

| 值 | 含义 |
|---:|---|
| 12 | 待付尾款 |
| 6 | 待付尾款 |
| 7 | 已付款 |
| 3 | 已转销售单 |
| 18 | 已取消 |
| 20 | 退款成功 |

## 订单状态 order_status

| 值 | 枚举 | 展示 |
|---:|---|---|
| 1 | `WAITDELIVERY` | 待发货 |
| 2 | `DELIVERIED` | 待收货 |
| 3 | `RECEIVED` | 已完成 |
| 4 | `WAITTAKE` | 待提货 |
| 5 | `TAKED` | 已自提 |
| 6 | `WAITPAY` | 待付款 |
| 7 | `PAIED` | 已付全款 |
| 8 | `CLOSED` | 已关闭 |
| 9 | `ALL` | 全部 |
| 10 | `WAITCLIM` | 待认领 |
| 11 | `PART_DELIVERY` | 部分发货 |
| 12 | `PART_PAY` | 部分已付款 |
| 18 | `CANCEL` | 已取消 |
| 19 | `LOCKED` | 已锁定 |
| 20 | `READYING` | 处理中 |
| 99 | `UNKNOWN` | 未知 |

## 测试关注点

- 支付状态、预售状态、订单状态是不同维度，不能混用。
- 预售的 6 和 12 都表示待付尾款，需要确认来源场景差异。
- 取消、退款成功订单是否进入销售指标，必须由指标口径决定。
- `WAITCLIM` 可能不是数据库存储状态，而是根据服务导购和执行导购是否存在动态判断。
